# Demo Easy downloads

[Download the presenter app](https://demo-easy.ardeesocials-07.workers.dev/downloads.html) · [Latest release](https://github.com/Ardee7/demo-easy-downloads/releases/latest)

1. Download the installer for Windows, Apple silicon Mac, or Intel Mac.
2. Install and open Demo Easy.
3. Paste your private presenter invitation link and click **Show overlay**.
4. Share your entire display in your meeting app.

The controller uses [Demo Easy in a browser](https://demo-easy.ardeesocials-07.workers.dev/session.html). Both people need internet access; they can be on different networks. Presenters do not need Git, Node.js, or the source repository.

Hover over the overlay to hide it temporarily; move away to restore it. **Cmd/Ctrl + Shift + O** toggles visibility. Keep invitation links private.

Initial Windows builds are unsigned and Mac builds are not notarized. Follow your organization's software policy if your operating system warns or blocks installation. Download newer installers manually to upgrade. SHA-256 checksums accompany each release.

This public repository distributes desktop installers only. Development history is maintained separately.
